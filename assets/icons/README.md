# assets/icons/

Исходники иконок полок — **Font Awesome Free (Solid)**, версия зафиксирована
зависимостью `@fortawesome/fontawesome-free` в `package.json` (7.3.1). Правка
иконки руками не имеет смысла: пересобирает их скрипт.

```
npm run icons:fetch
```

Скрипт берёт SVG из `node_modules/@fortawesome/fontawesome-free/svgs/solid/`,
нормализует оптику (общий вес и общая нижняя кромка в квадрате 24×24) и
пересобирает:

- блок `ICONS` в `src/renderer/CategoryIcon.tsx`;
- те же иконки в шапке README (`assets/readme/hero.svg`).

## Почему Font Awesome, а не набор с тонкими контурами

Пиктограммы еды в «шрифтовых» наборах абстрактны: в колонке полок «у молока
коробка», «у масла окно», «у сыров рыба» — и половина полок не читалась. Здесь
каждая полка названа своим предметом: сыр, ножка, бекон, морковь, яблоко,
канистра бытовой химии. Набор один, стиль один (сплошные силуэты).

## Нормализация оптики

Общая сетка не даёт общей оптики: высота чернил у глифов гуляет (в исходниках
Font Awesome — от 514 до 880 юнитов, в 1,7 раза), и часть иконок читалась бы как
«крупный знак», часть — как «мелкий значок в пустом квадрате». Поэтому каждому
глифу записаны `s`/`dx`/`dy`: общий вес (20 юнитов из 24) и общая нижняя кромка
(22 юнита). Считает их `scripts/fetch-fontawesome-icons.ts`, проверяет
`npm run test:icons`.
